# Grow My Therapy

A responsive counseling website built as part of the
Grow My Therapy Front-End Developer Internship assessment.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Goals

- Recreate the reference homepage layout.
- Redesign the website using the provided therapist profile.
- Create responsive desktop and mobile layouts.
- Add a custom Our Office section.

## Getting Started

Install dependencies:

npm install

Run the development server:

npm run dev

Open http://localhost:3000 in your browser.
